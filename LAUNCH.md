## Deploy to Cloudflare Pages

### 1. Push to GitHub
```bash
cd ~/querydrop
git init
git add .
git commit -m "feat: querydrop v1.0.0"
gh repo create querydrop/querydrop --public --source=. --remote=origin --push
```

### 2. Connect Cloudflare Pages
1. Go to https://dash.cloudflare.com → Pages → Create application → Connect to Git
2. Select `querydrop/querydrop` repo
3. Build settings:
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
   - **Root directory:** *(leave blank)*
   - **Node version:** `20` (or `22`)
4. Save and Deploy. First build ~2 min, subsequent ~30s.

### 3. Custom domain
1. Cloudflare Pages project → Custom domains → Set up a custom domain
2. Enter `querydrop.com` (and `www.querydrop.com` if you want both)
3. Cloudflare auto-adds the CNAME. If your DNS is on a different registrar, add:
   ```
   querydrop.com   CNAME   querydrop.pages.dev
   www             CNAME   querydrop.pages.dev
   ```
4. Cloudflare auto-provisions the Let's Encrypt cert (no action needed)

### 4. HSTS preload (optional but recommended)
The `_headers` file already sets `Strict-Transport-Security: max-age=31536000; includeSubDomains`. To submit for browser preload list: https://hstspreload.org/?domain=querydrop.com

## Verify post-deploy

```bash
# Status
curl -I https://querydrop.com

# Headers (should include COOP/COEP/HSTS)
curl -I https://querydrop.com/tool | grep -iE "cross-origin|strict-transport"

# Sitemap
curl https://querydrop.com/sitemap-index.xml

# Robots
curl https://querydrop.com/robots.txt

# Service worker (must be served from root scope)
curl -I https://querydrop.com/sw.js
```

In Chrome DevTools on https://querydrop.com:
1. **Application → Service Workers** → confirm `sw.js` activated, scope = `/`
2. **Application → Manifest** → confirm installable, icons listed
3. **Application → Storage** → confirm SW caches populated after navigation
4. **Lighthouse** → run audit; targets: Performance 85+, Accessibility 95+, Best Practices 100, SEO 100
5. **Network → throttling Slow 4G** → drop a 10MB CSV, confirm DuckDB-WASM streams from SW cache
6. **Lighthouse → PWA** → confirm "Installable" + "PWA-optimized"

## Optional: Plausible analytics

1. Sign up at https://plausible.io (paid — $9/mo) OR self-host (free, needs your own server)
2. Add `querydrop.com` as a site in Plausible dashboard
3. Open `src/scripts/analytics.ts` and change `data-domain` to your Plausible domain
4. Rebuild + redeploy
5. Visitors must click "Help improve QueryDrop" in the footer to opt in (default: off)
6. Verify in Plausible dashboard: only opted-in visits appear

If you skip Plausible entirely, no script loads. The toggle still works as a no-op.
